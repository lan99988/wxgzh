公众号文章生命周期与目录结构示例
====================================

推荐采用三状态文件夹管理文章：
  待办/  -> 在办/  -> 办结/

单篇文章在「在办」状态的完整目录：

在办/01-示例文章/
├── 01-示例文章_v5.3版.md              ← 原始稿件
├── 01-示例文章_v5.3_配图版.md         ← 插入配图后
├── 01-示例文章_v5.3_配图版.html        ← 排版 HTML
└── imgs/
    ├── cover.png
    ├── 01-xxx.png
    ├── ...
    └── prompts/
          ├── 00-cover-xxx.md
          ├── 01-xxx.md
          └── ...

发布前草稿目录 (drafts/YYYYMMDD-slug/):

drafts/20261231-示例文章/
├── article.yaml      ← 元数据
├── article.md        ← 含配图 Markdown
├── article.html      ← 最终 HTML
├── cover.png
└── imgs/
    ├── 01-xxx.png
    └── prompts/

状态流转:
  1. 新文章 -> 待办/
  2. 开始配图排版 -> 在办/
  3. 配图排版完成 -> drafts/ 准备发布
  4. 发布完成 -> 办结/ 归档
